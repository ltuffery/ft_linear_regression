# ft_linear_regression
Machine Learning

## Quick Start
### Create virtual environment
```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
```

### Train model
```bash
python3 train_model.py
```

### Predict price
```bash
python3 predict_price.py
```

### Display plot
```bash
python3 plot.py
```

### Deactivate
```bash
deactivate
```
